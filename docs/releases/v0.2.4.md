# Emerald YM 0.2.4 — instrument selection and level

Historical controls: SELECT chooses one of 12 sources; ALGORITHM sets only its level 0–100%, 5% steps, initially 100% of the accepted balance. The PSG calibration from 0.2.2 remains. PRESETS is still an additional DAC/noise percussion bus; MASTER is global. ARP toggles all PSG. REC/pause/selection retain levels; reboot restores defaults without a flash save.

Source order: FM BASS, FM LEAD, FM CHORD 1–3, KICK, SNARE, CLOSED HAT, OPEN HAT, PSG ARP, PSG LIVE (up to three keyboard voices), PSG NOISE. Bottom tiles show selected source/ALG level and PRE DRUM bus. CPU/XRUN remain USB-only;85% guard/OVERLOAD unchanged.

Each FM channel is scaled after its DAC discontinuity, before percussion; unity bypasses multiplication. Drum gains update at trigger/block boundaries, including active tails. Arp/live/noise have separate multipliers. No extra operators, renderer allocations, libm or double. The PSG-divider table moves to setup-time XIP .ym_pitch, not the oscillator sample loop; active periods/hot code remain RAM. No memory-region/startup changes; flash-off .ram_text still cannot call XIP. Main-loop leaf controls remain .ym_control.

Desktop tests isolate all 12 sources after initial transients, mute/restore held live notes, match default hash 7ce44fbe to 0.2.2 across blocks 256/63, and check reseed/pause/no allocation. SELECT/ALGORITHM update only the 148×34 source tile; PRESETS the 72×34 tile. USB counters cause no LCD writes. LED/PSG/linker/no-soft-double/OTA/loader passed; inherited JS comparison skipped, not passed. UI preview is a desktop render.
