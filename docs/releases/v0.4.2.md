# Emerald YM 0.4.2 — PR candidate

The main title now reads Emerald YM. A 48×20 16-BIT badge replaces the 62×27 badge, leaving a visible gap above the version label. The full title fits before the badge; changed-tile redraw behavior is retained.

Settings schema 2 is 72 bytes: the existing 56-byte prefix plus uint32 tempo/density/mutation and int32 transpose. Bounds are 80–180 BPM, 0–100 density/mutation and −12..+12 semitones. Invalid records are rejected atomically. Legacy schema 1 keeps all twelve levels/36 FX values with default knob values. Migration itself performs no flash write; an actual change and quiet save commits schema 2. Downgrading to 0.4.0 cannot load schema 2 and uses defaults.

K1–K4 and SEQ edits mark settings dirty only when values change. The existing A/B CRC/header-last commit, three-second edit/quiet debounce, pause-only writes, explicit failure retry and SAVE behavior remain. Seed, master, PSG enable and selection/cursor are not stored. Audio starts paused and receives restored parameters before audio_init.

Desktop tests cover all knobs and signed transpose, lower/upper/invalid bounds, reboot restoration, schema 1 migration without writes, first migrated save, corruption/interruption fallback, timer wrap and actual UI/LED/OTA/loader/installer paths. The inherited JS comparison remains skipped. No hot DSP, memory region, 85% guard or flash-off code changes. RAMTEXT 24492/24576 B; hot audio 21604 B; data+BSS 30416/98304 B; pool 101888/344064 B; application 105352 B.
