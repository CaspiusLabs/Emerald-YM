# Emerald YM 0.3.0 — three effects per instrument

Twelve instruments each have independent DECAY/COLOR/ECHO amounts 0–100%, initially 0. FX selects the edited parameter without disabling others. In this version PRESETS edits effects and ALGORITHM volume; after accepting the effects, the user requested their swap in 0.3.1.

## Sound and limits

- DECAY increasingly shortens notes: FM gate/release, drum/noise segment, PSG arp gate. Live PSG held-note duration runs roughly 1 s down to 20 ms for nonzero values. Zero retains the original articulation/sustain.
- COLOR is source-specific: FM modulation/feedback; drum bit reduction; PSG tone ring-modulation blend; three noise-clock ranges. It is not a single shared filter.
- ECHO has per-source sends into one stereo line at 22.05kHz, approximately 186 ms. Paired input samples are averaged; FM sends follow native resampling/interpolation. int 16 buffer, feedback 5/16 and moderate return gain. Neither twelve independent delays nor tempo synchronization is provided. Tails decay after sends are disabled; REC invalidates history through generation tags instead of clearing the large buffer in the IRQ.

Source articulation/color/level feeds the echo send; the shared return precedes MASTER/output limiting. Existing tails may remain after muting a source. Settings are volatile. FX is dim with all selected-source effects zero, bright with any nonzero. Changing source/parameter does not clear values.

## Optimization and memory

EMERALD_STATIC_OPN skips unused SSG-EG, AM and dynamic PM steps. Current patches/FX never enable them. Adding them requires adapting/disabling this profile. EMERALD_GENERIC_OPN restores the prior operator paths while retaining five FM + fixed DAC. Generic and optimized dry-minute hash 7ce44fbe (as 0.2.2) and FX-scene hash f9fae4ef match. Run tools/test-ym-generic-windows.cmd without MIDI/flashing.

FX and less frequent note/configuration functions use .audio_hot.fx inside the original .audio_hot startup copy and PC guard ending at _audio_end. Region limits, debug/STATUS reserve and data/stack protections remain unchanged. Patch/configuration tables in XIP .ym_pitch are outside sample loops. Echo buffers/tags use 32 KiB of the original pool.

RAMTEXT 24492/24576 B; data+BSS 30320/98304 B; pool 101888/344064 B. Linker checks copy/PC coverage. The 85% guard, no-soft-double, flash-off call checks and no render allocation remain.
