# Emerald YM 0.2.1 — clearer PSG arpeggio

Historical development from accepted 0.1.4; original package/tag/evidence preserved.

PLAY pauses backing; F3–G5 keys play up to three PSG voices including pause. ARP toggles all PSG. REC reseeds, SEQ toggles mutation 0/35; K1–K4/MASTER unchanged. Three live voices displace only PSG arp. Latest pressed notes take priority and older held notes return; simultaneous changes favor higher keys, not a live arpeggiator. Bright LEDs mark assigned live physical keys (also after K4 transpose), dim LEDs mark gated in-range backing notes, not release tails/out-of-range notes. USB notes 53–79 on all channels join panel keys; CC120/123 clears USB notes; velocity is gate only.

Original lightweight Sega PSG musical profile: NTSC 3579545 Hz, three 10-bit tone dividers,2 dB attenuation and white-noise clock/512 with 16-bit LFSR taps 0/3. Edges are integrated within each sample; software envelopes are instrument behavior. Not a complete register/VGM/noise-mode/PCM player. Research reference: https://www.smspower.org/Development/SN76489 . Code is original/MIT; combined firmware GPL-3.0-only.

Arp is6dB louder than 0.2.0, an octave lower, longer gated, repeating current chord tones 0–1–2–1 rather than independent random notes. FM has fixed 0.85 headroom coefficient in the mix.

Desktop tests cover blocks 256/63, seeds/pause/extremes/no allocations, PSG A4/LFSR period and optimized integration vs independent reference, three-voice steal/return, pause, disable, reseed with held keys/release, actual UI/LED and OTA/loader simulation. Build checks no-soft-double, flash-off calls, RAM placement, unchanged map/85% guard; RAMTEXT has little spare room.
