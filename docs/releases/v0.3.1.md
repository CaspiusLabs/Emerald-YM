# Emerald YM 0.3.1 — encoder swap

After the user's acceptance of 0.3.0 FX, SELECT still chooses the source; PRESETS now adjusts its level 0–100% (PRE tile), FX cycles DECAY/COLOR/ECHO, and ALGORITHM adjusts that effect 0–100% (ALG tile). All three amounts remain independently active. PRESETS is no longer a global drum bus. Levels/effects survive selection, pause and REC but reset on reboot; no automatic flash save.

DSP, memory layout and MIDI protocol are identical to 0.3.0. Only the encoder assignments, UI labels and version changed. PLAY/REC/SEQ/ARP, keys and note LEDs remain. See [0.3.0](v0.3.0.md) for DSP details.

Desktop audio/FX/UI/LED/update simulations passed. The installed USB identity was FM-1_68000301. A 30-second continuous physical backing-plus-live run with neutral FX passed: CPU MAX 65%, longest block 3820 us, XRUN 0, overload 0. All-FX physical stress belongs to 0.3.0 with the same DSP; it is not relabeled as a 0.3.1 measurement. Test notes were released and ordinary backing restarted afterward.

The swapped physical controls await separate user confirmation. Package, logs and separate offline/hardware reports are in releases/v0.3.1. The screenshot is a desktop render, not a photograph. Public-listing update transitions remain unverified; see ../FIRMWARE-HUB.md.
