# Emerald YM 0.3.1 — zamiana ALGORITHM i PRESETS

Na życzenie użytkownika po akceptacji efektów 0.3.0:

- SELECT wybiera instrument.
- PRESETS reguluje jego głośność 0–100% (pole PRE).
- FX wybiera DECAY / COLOR / ECHO do edycji.
- ALGORITHM reguluje wybrany efekt 0–100% (pole ALG z nazwą efektu).

Pozostałe efekty pozostają aktywne, a poziomy wszystkich instrumentów zachowane
w czasie sesji. PRESETS nie jest już globalną głośnością perkusji. Każdy bęben
ma własny poziom przez SELECT + PRESETS. Zero efektu to ustawienie neutralne;
restart przywraca domyślne poziomy i zerowe efekty. Brak automatycznego zapisu Flash.

Silnik audio, efekty, optymalizacja i układ pamięci są identyczne z 0.3.0.
Opis i ograniczenia: [v0.3.0.md](v0.3.0.md). Zmieniono wyłącznie powiązania
dwóch fizycznych enkoderów i oznaczenia UI. MIDI CC20–22 oraz protokół statusu
pozostają bez zmian. Przyciski PLAY/REC/SEQ/ARP, klawiatura i LED nut bez zmian.

Testy desktopowe FX, renderera, GUI/LED i symulacji aktualizacji przeszły.
Wyniki weryfikacji pakietu i fizycznej instalacji są zapisywane oddzielnie
w releases/v0.3.1. Podgląd UI jest renderem testowym, nie zdjęciem urządzenia.

Po instalacji tożsamość USB: FM-1_68000301. Test fizyczny 30 s ciągłego podkładu
z dodatkowymi nutami live i neutralnymi FX przeszedł: CPU MAX 65%, maksymalny
blok 3820 us, XRUNS 0, przeciążenia 0. Próba wszystkich FX należy do 0.3.0
(ten sam DSP); nie jest oznaczana jako pomiar 0.3.1. Po próbie wyłączono nuty
testowe i uruchomiono zwykły podkład.
