# Emerald YM 0.2.0 — PSG i klawiatura live

Wersja rozwojowa zastąpiona przez 0.2.1 po uwagach z odsłuchu.
Identyfikator FM-1_68000200. Zachowany końcowy pakiet jest w releases/v0.2.0.
SHA-256: fced6dee71473d1821fd8143fd358b150688d717a243fd7ffcaa7084b7e33738.

Dodano profil Sega PSG, trzy głosy live, ARP on/off i LED-y nut. Wszystkie
dotychczasowe głosy FM i DAC pozostają. Wynik desktopowy, symulacje OTA/loadera
i kontrole linkera przeszły. Mapa pamięci oraz próg ochronny 85% bez zmian.

Próba końcowego pakietu przez około 60,7 s zebrała 62 odczyty, w tym 60 w oknie
testowym. Podkład był aktywny w 47 z nich, więc to próba interaktywna.
CPU MAX 84%, max blok 4910 us, XRUNS 0, overload 0, failed boots 0.
Przez standardowe MIDI dodawano dwie/trzy nuty PSG. Surowy raport zachowuje
passed=true według ówczesnego kryterium, które dopuszczało pauzy.
Nie oznacza to potwierdzenia minuty nieprzerwanego odtwarzania.

Osobny test ciągły został przerwany brakiem jednej odpowiedzi statusu USB.
Po wysłaniu Stop urządzenie odpowiedziało ponownie; ostatni odczyt nadal
miał XRUNS 0 i overload 0. Zachowano log jako hardware-continuous-incomplete.log.
Test nie został uznany za zaliczony; timeout nie dowodzi ani błędu audio,
ani poprawnego zakończenia testu. Nowszy skrypt zapisuje też częściowe raporty.

Użytkownik potwierdził podświetlenie klawiszy. Ocenił arpeggio PSG jako za ciche
i brzmiące przypadkowo; 0.2.1 zmienia jego poziom, oktawę, długość nut i wzór.

Wcześniejszy prototyp przed optymalizacją dochodził do CPU MAX 85% przy
XRUNS 0. Nie utożsamiamy jego wyników z zachowanym końcowym pakietem.
